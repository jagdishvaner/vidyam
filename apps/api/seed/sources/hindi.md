# Hindi syllabus: sources and judgement calls

Checked 27 Oct 2026. Primary sources only. Coaching-site summaries were read for orientation but not relied on.

## Judgement calls

- **REET.** BSER has not republished a separate language syllabus since the 2015 PDFs. The 2021, 2022 and 2024 cycles reused the same Language I/II content, but this is an assumption worth rechecking when the next REET notice appears.
  - Level 1 and Level 2 list identical Hindi content.
  - Language I and II differ only slightly: II adds the unseen poem and कारक चिह्न, while I adds पर्यायवाची/विलोम/एकार्थी. All three REET papers link the union of the two.
- **RPSC grammar.** खंड I is identical for 2nd Grade and 1st Grade, so both papers link the same grammar nodes.
  - 2nd Grade lists 12 named alankars and 10 named chhands. The tree has a subtopic for each, and RPSC links exactly those.
  - अनुप्रास and मानवीकरण are included in the tree for CBSE and REET.
- **छायावादोत्तर युग (2nd Grade)** is read as covering the whole post-Chhayavad span: प्रगतिवाद, प्रयोगवाद and नयी कविता. So 2nd Grade links the whole "Development of Modern Hindi Poetry" chapter.
- **Prescribed texts.** Each work is one topic, shared by both RPSC papers where they overlap. Where the papers differ, the node covers both:
  - Bihari Ratnakar: 20 dohe for 2nd Grade, 25 for 1st Grade.
  - Kabir: same selection in both.
- **School Lecturer खंड IV** (teaching models and ICT) is generic pedagogy common to all subjects. It sits in the Hindi pedagogy unit so that `rpsc_1g_p2_hindi` can link it. The English tree has its own copy.
- **CBSE Class 10.**
  - `cbse_class_10` links the union of Course A and Course B, because the catalog has one CBSE Class 10 paper.
  - The CBSE 2026-27 PDF still lists some lessons as "not for examination" (देव, छाया मत छूना, कन्यादान, स्त्री-शिक्षा…, मानवीय करुणा…, बिहारी, मधुर-मधुर मेरे दीपक जल, गिरगिट…). Those lessons are no longer in the NCERT 2026-27 reprints, so the tree follows the reprint lesson lists (12, 3, 14 and 3 lessons).
- **RBSE Class 10** uses NCERT Kshitij-2 and Kritika-2, so it links the same textbook chapters as CBSE Course A.
- **Graduation and PG-level material** sits in its own units: काव्यशास्त्र, साहित्य का इतिहास, हिन्दी भाषा and निर्धारित पाठ.
- **Extra nodes for completeness.** A few nodes are not line items in any listed syllabus but are standard and regularly examined: संकर शब्द, रूढ़/यौगिक/योगरूढ़, निपात, विराम-चिह्न, संस्मरण/रेखाचित्र and हिन्दी आलोचना.
- **Weightage is omitted throughout.** The marks schemes (RBSE section marks, CBSE section marks, REET 30 questions per language) do not map one-to-one onto single nodes.
